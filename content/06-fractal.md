title: A component is a network; a network is a component.

There is no privileged level. A leaf is an atomic component. A network is a composite component that satisfies the same contract. The pipeline is a component. The runtime is a component. The agent is a component.

That self-similarity is not decoration. It is what lets one verification rule hold at every scale: if composition preserves determinism and verifiability, then the whole is exactly as provable as its parts.
