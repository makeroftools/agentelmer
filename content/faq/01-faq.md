```html
<div class="faq">
  <details open><summary>Is this a blockchain?</summary><p>No. Agent Elmer is content-addressed and deterministic, not a global chain. Coordination stays with the agent — there is no world-state to agree on, so there is nothing to centralise.</p></details>
  <details><summary>Do I need to be a programmer?</summary><p>No. You describe what you need and the factory builds it. Developers can also use the engine directly as a runtime for components and agents.</p></details>
  <details><summary>Who owns what I make?</summary><p>You do. Your data is yours. Components you create carry your rights as their holder — the terms are being finalised for the peer-to-peer stage.</p></details>
  <details><summary>Is it open source?</summary><p>The Agent Elmer free core is open on GitHub. Pro and Enterprise add team, placement, and support features.</p></details>
  <details><summary>Where does it run?</summary><p>Locally or on your own infrastructure. Runtime endpoints are ephemeral and replaceable; identity is stable.</p></details>
  <details><summary>When does Creative Development ship?</summary><p>It is on the roadmap, built on Agent Elmer. The engine ships first — the world is built on it.</p></details>
</div>
```
