Investor one-pager

The execution layer for agents that do real work.

Coding agents are getting capable enough to run for hours. They are still built like chat sessions: one process, one turn, one fragile transcript. Agent Elmer fixes the product side with durable execution and the trust side with a deterministic substrate.

Thesis

Coordination belongs with the agent.

The last decade bet that value would concentrate in a single global ledger. We bet the opposite: software should be agent-centric, deterministic, and content-addressed — reproducible rather than agreed-upon. Agent Elmer is that bet, built.

The model is the instrument, not the authority. The human is the clamp. A system that meticulously labels what it has not proven is the opposite of one that guesses.

The problem

The models arrived. The trust did not.

Lost work

Chat is not a checkpoint.

Kill the process and the work is gone. A transcript is not an audit trail, and a retry is not a recovery.

Serial work

One agent at a time.

Run one agent and the rest of the team waits. Parallelism without bounds is not a solution; it is a new failure mode.

Unprovable work

Prose, not evidence.

Ask what happened and you get a summary. You cannot replay it, compare it, or prove that two runs agree.

The product

Durable execution, bounded parallelism, deterministic proof.

What the user experiences

  • Close the browser or kill the backend; the run resumes from its last checkpoint.
  • Fan out independent work; the join is deterministic and the result is addressed.
  • Work tracks are bounded, inspectable, and merged by a coordinator.
  • Devices render the same actions; collaboration is a projection, not a second product.
  • Every result can be replayed and checked against the recorded floor.

What the system guarantees

  • Same pinned inputs produce the same addressed outcome.
  • Evidence fields never enter addressed output.
  • Delivery is at-least-once with dedupe; the promise is exactly-once reporting and effect.
  • A check that cannot pass refuses.
  • The operator is the sole ratifier.
